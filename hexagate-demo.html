About ShieldFi

            
ShieldFi is a protocol and wallet security console powered by Hexagate, with Chainalysis Address Screening for wallet risk. It demonstrates real time monitoring, custom Gate DSL rules, and address screening. Use it when demoing to protocols, stablecoin issuers, bridges, and exchanges.

          

        

        

          
Presenter workflow

          
1
Pick a use case and create a monitor
Choose whether you are watching contracts or hot wallets, then create a real monitor with the Hexagate Monitor API and show it join the monitors already running on every block.

          
2
Show Gate DSL on live data
Open Gate DSL, lower the threshold, and run it. Hexagate queries the live chain and the rule breaches, raising an alert. Raise the threshold and it stays in policy. That is the customizable engine behind every monitor.

          
3
Screen a wallet
Use Address Screening to show how Chainalysis adds wallet and counterparty risk on top of Hexagate's on chain monitoring.
