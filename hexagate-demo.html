Gate DSL, Custom Monitoring Rules

Write custom detection logic using Hexagate's domain-specific language. Rules are evaluated on every block in real-time. Below is an example rule that monitors unusual USDC transfer volume.

usdc-volume-monitor.gate
use Events, Sum from hexagate; // USDC contract address on Ethereum source usdc: address = 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48; // Fetch all Transfer events from the current block source transfers: list<tuple<address, address, integer>> = Events { contract: usdc, signature: "event Transfer(address indexed from, address indexed to, uint256 value)" }; // Sum all transfer values in the block source totalVolume: integer = Sum { sequence: [transfer[2] for transfer in transfers] }; // Alert if single-block volume exceeds $10M (10M * 10^6 decimals) rule { description: "Unusual USDC transfer volume detected", condition: totalVolume < 10000000000000, severity: "HIGH" };

About ShieldFi

Smart Contract Security, Compliance Cove Demo

What This Demo Shows

ShieldFi is a DeFi protocol security dashboard powered by Hexagate. It demonstrates real-time smart contract monitoring, address risk analysis, transaction simulation, approval workflows, and Gate DSL custom monitoring rules. Use this when demoing to DeFi protocols, bridges, or any project with smart contracts.

Presenter Workflow

Follow these steps during a customer call. Each step includes a talking point you can use.

1

Overview, Show Protocol Health

Start on the Overview tab. Highlight TVL, monitored contracts, active alerts, and uptime. Click through the contract list to show Hexagate monitoring per protocol.

💬 Talking Point: This is your protocol's security command center. Hexagate monitors every contract in real-time, reentrancy, oracle manipulation, and exploit patterns trained on 200+ real attacks.

2

Address Analysis

Switch to Address Analysis. Use the pre-screened picker to analyze the BAYC contract (Low) or Lazarus Group address (Severe).

💬 Talking Point: Any address interacting with your protocol can be analyzed instantly, risk level, entity type, and security issues. This is how you gate who can interact with your smart contracts.

3

Transaction Simulation

Switch to Tx Simulation. Click 'Simulate Transaction' with the pre-filled fields. Show the warnings and state changes.

💬 Talking Point: Before a large transaction executes, simulate it first. See the state changes, token approvals, and risk warnings BEFORE it hits the blockchain.

4

Gate DSL

Switch to Gate DSL. Show the syntax-highlighted USDC volume rule. Click 'Validate' to run it against a real Ethereum block.

💬 Talking Point: Gate is Hexagate's custom monitoring language. Write rules like 'alert if single-block USDC volume exceeds $10M'. The rule runs on every block in real-time.

5

Approvals Workflow

Switch to Approvals. Show the contract upgrade pending sign-off and the emergency pause triggered by IntelliGate. Approve or reject.

💬 Talking Point: When Hexagate detects a threat, it can auto-pause your protocol. The security team then reviews the simulation, signs off, and either resumes or maintains the pause.
