Wash Trading Detection Methodology

Chainalysis Data Solutions uses on-chain transaction tracing to identify wash trading patterns in prediction markets. By analyzing wallet clusters, transaction timing, and fund flows, we detect six distinct patterns of artificial volume generation.

Self-Trades

The simplest form — a trader buys and sells the same contract position using the same wallet or wallets within the same cluster. Creates artificial volume with zero actual market risk.

Detection: Cluster analysis links wallets to the same entity. Data Solutions identifies when the same cluster holds both YES and NO positions.

Round Trips

Funds move in a circle: Wallet A sends to Wallet B, which trades, then sends proceeds back to Wallet A. The net position is zero but volume is inflated.

Detection: Transaction tracing shows funds returning to the originating wallet within a configurable time window.

Pass-Through

An intermediary wallet is used to obscure the relationship. Wallet A sends to Wallet C (the pass-through), which then trades on the market. C is controlled by the same entity as A.

Detection: Chainalysis cluster attribution links the intermediary to the original entity despite the extra hop.

A-B-A Wash Trades

Two wallets controlled by the same entity trade with each other. A sells YES to B, B sells NO to A — both sides of the trade are the same person, generating fake volume and manipulating the odds.

Detection: On-chain funding analysis reveals both wallets were funded from the same source or share the same withdrawal destination.

Circular Currency Pair

A trader exploits correlated markets — buying YES on "BTC > $100K" while selling YES on "BTC > $95K" across different wallets, creating synthetic hedges that inflate volume in both markets.

Detection: Cross-market correlation analysis identifies offsetting positions held by the same cluster across multiple event contracts.

Multi-trade Wash

The most sophisticated pattern — a coordinated network of 5+ wallets execute a series of trades designed to look organic. Each individual trade appears legitimate, but the network analysis reveals coordinated behavior and volume inflation.

Detection: Graph analysis + timing correlation. Chainalysis traces the funding source of all participants and identifies coordinated transaction timing.
